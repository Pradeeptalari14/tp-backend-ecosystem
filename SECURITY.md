# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
To report a security vulnerability in this project:
1. Please do not open public GitHub issues.
2. Email `security@pradeeptalari.com` with vulnerability reproduction steps and affected components.
3. We will respond within 48 hours with an initial assessment and mitigation timeline.
